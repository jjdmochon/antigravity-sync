Read this with the numbers. Tm is the Giesen PNA/DNA regression (±5 K for >90% of sequences) — rank with it, do not quote it as a prediction; an RNA target is folded to DNA and PNA·RNA is more stable, so values are conservative. Gamma stabilisation is not quantified (offset defaults to 0). Mass windows must use the tagged reagent increment. Off-target cross-hybridisation is not screened. The score is a screening heuristic, not a yield model — an experimentally validated probe outranks it; paste it above and it is pinned into the panel.
